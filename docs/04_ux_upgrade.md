# UI/UX アップグレード — 監査と設計（2026-09-24）

学習ロジック（engine/*）・データ・回答履歴には手を入れない。変更は UI 層と、それを支える純粋関数（engine/celebration.ts）の追加のみ。

## 1. 現状監査（摩擦の一覧）

| # | 画面 | 摩擦 | 影響 |
|---|---|---|---|
| F1 | 問題 | 「自信あり」を押してから DB 保存完了まで正誤が出ない（数十ms〜） | 「押せたかな？」 |
| F2 | 問題 | 次の問題が瞬間的に差し替わる。スクロール位置だけ飛ぶ | 文脈が途切れる |
| F3 | 問題 | 不正解時「正解は ウ でした」が見出しで、先に“失敗”が来る。なぜ自分の選択が違うかが「詳しく」の奥 | 失敗感＞納得感 |
| F4 | 問題 | 正誤が主に色（緑/テラコッタ）で表現 | 色覚・一瞥性 |
| F5 | 全体 | ボタンに押下フィードバックなし | 触感がない |
| F6 | ホーム | 同じ重さのカードが3枚並び、主CTAと情報が同列。数字の変化が見えない | 3秒で要点が取れない |
| F7 | ホーム | 今日のメニュー内容（何をやるか）が見えない | 「今日は何を？」が残る |
| F8 | 結果 | 完了の瞬間の演出・成長の可視化がない | 達成感が弱い |

| F10 | 読込 | ready 前は空白 | 一瞬の白画面 |

## 2. Visual Hierarchy（上から重い順）

1. 今日やること（CTA・残り日数・今日の進捗）… 28/700 と 18/600、CTA 56px
2. 問題文 … 17px / 1.8
3. 選択肢・回答 … 16px / 600 ラベル
4. 解説（結論 → 違い → 一言記憶）… 15px
5. 補助（出典・根拠・詳細）… 12–13px muted

## 3. UI State（共通の状態遷移）

| 状態 | 表現（色だけに頼らない） |
|---|---|
| Default | 背景 surface、1px border |
| Pressed | scale(.97)、100ms |
| Selected | primary の 2px border＋ラベル反転（塗り） |
| Correct | ✓アイコン出現（scale+fade 240ms）＋「正解」テキスト＋success の左ボーダー |
| Incorrect | 「あなたの回答」テキスト＋落ち着いた warm 背景（赤は使わない）、振動なし |
| Disabled | opacity .45、押下なし |
| Loading | スケルトン（シマーは reduced-motion で停止） |
| Completed | ✓バッジ＋「完了」テキスト |

## 4. Celebration Hierarchy（engine/celebration.ts）

| Lv | 条件 | 演出 | 頻度制御 |
|---|---|---|---|
| 1 | 正解 | ✓が軽く出現・極軽ハプティクス | 毎回（控えめ） |
| 2 | セッション内3問連続正解 | 小さなチップ「3問連続」 | 3のときだけ |
| 3 | 5・10問連続正解 | 小規模紙吹雪（24粒） | 5と10のときだけ |
| 4 | 苦手テーマ克服（2問以上・理解度50%未満 → 65%以上） | 紙吹雪＋実績「◯◯を習得しました」 | テーマごとに一度 |
| 5 | 今日の目標問題数を達成 | 最大の紙吹雪＋完了画面 | 1日一度 |
| 6 | 学習フェーズの移行 | 特別な実績表示 | フェーズごとに一度 |
| Delight | 7日継続／試験まで30日／頻出テーマ全習得／昨日より理解度↑ | 実績 or 小さな↑ | それぞれ一度 |

褒める対象は「問題数」ではなく「理解・苦手克服・継続・必要な学習の完了」。

## 5. Design Tokens

- Spacing: 8pt grid（4/8/12/16/24/32/48）
- Radius: 12（部品）/ 16（面）/ 999（チップ）
- Motion: fast 120ms・base 200ms・slow 320ms・count ≤500ms、easing `cubic-bezier(.2,.8,.2,1)`
- Color: Neutral（bg/surface/ink/muted/line）＋ Primary（藍）＋ Success（深緑）＋ Subtle warning（琥珀寄りの warm）。赤は使わない。
- アニメーションは transform / opacity のみ。進捗バーは scaleX。

## 6. 実装範囲

Microinteraction（押下・選択・✓）/ 楽観的UI（F1）/ 問題トランジション（F2）/ 不正解の説明順（F3・F4）/ 紙吹雪（canvas・終わったら停止）/ 進捗・数値のカウントアップ / 完了体験と成長（昨日→今日）/ 下部ナビ4つ＋設定はホーム右上 / スケルトン / ハプティクス（対応端末のみ・既定ON）/ サウンド（既定OFF・不正解音なし）/ reduced-motion 対応
